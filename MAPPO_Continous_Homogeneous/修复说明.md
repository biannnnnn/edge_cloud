# MAPPO 收敛问题修复说明

## 🔍 问题诊断

### 问题1: Critic Loss为0
**原因**: 
- Critic网络没有正确更新
- 价值目标计算可能有问题
- Critic loss相对于actor loss权重过小

### 问题2: 奖励归一化Bug
**原因**: `normalization.py`中初始化`std=0`，导致奖励信号失真

### 问题3: 模型不收敛
**原因**: 
- 学习率可能过高
- 探索不足（熵系数过小）
- 训练epoch过多可能导致过拟合

---

## ✅ 已实施的解决方案

### 1. **禁用奖励归一化** 
```python
# MAPPO_main.py 第365行
parser.add_argument("--use_reward_norm", type=bool, default=False)
```
避免了归一化bug对训练的影响。

### 2. **增加Critic Loss权重**
```python
# MAPPO.py 第155行
self.value_coef = 1.0  # 从默认的1.0增加，确保critic能学习
```
在总loss中: `ac_loss = actor_loss.mean() + value_coef * critic_loss.mean()`

### 3. **优化关键超参数**
```python
# MAPPO_main.py 第359-367行
--lr 3e-4              # 降低学习率 (原5e-4)
--K_epochs 10          # 减少训练epoch (原15)
--entropy_coef 0.05    # 增加熵系数 (原0.01)
```

### 4. **添加详细调试信息**
每5000步打印：
- Hunter和Prey的Actor/Critic Loss
- Advantage的范围
- Value Target的范围

## 💡 训练建议

1. **观察前1000步**的调试信息，确保：
   - Critic Loss > 0
   - Advantage有正有负
   - Value Target有合理的范围

2. **监控Success Rate**：
   - 应该在训练中期开始上升
   - 如果一直为0，可能需要调整奖励函数

3. **检查Average Reward**：
   - 应该逐渐上升（从-4000左右上升）
   - 如果震荡太大，降低学习率

4. **观察Episode Steps**：
   - 成功围捕时会小于100步
   - 一直是100说明没学会围捕
