# 奖励函数重新设计说明

## 🎯 设计目标

解决原奖励函数导致的"原地不动"问题：
- **旧问题**：移动可能带来碰撞惩罚(-50)，而原地不动只有时间惩罚(-1)
- **新目标**：鼓励猎人主动接近猎物，即使在包围状态下也要继续缩小距离

---

## 📊 新奖励函数组成

### 1. **接近奖励（核心机制）** ⭐
```python
for i in range(3):
    distance_change = prev_distance[i] - current_distance[i]
    if distance_change > 0:  # 接近了
        approach_reward += distance_change * 2.0
    elif distance_change < 0:  # 远离了
        approach_reward += distance_change * 0.5
```

**特点**：
- ✅ 每步接近1格 = +2.0奖励
- ⚠️ 每步远离1格 = -0.5惩罚
- ⚪ 原地不动 = 0（由静止惩罚处理）
- 📈 **正反馈**：越接近猎物，获得的奖励越多

### 2. **静止不动惩罚**
```python
if action == 0:  # 不动
    static_penalty -= 2.0
```

**特点**：
- 每个静止的猎人 = -2.0
- 强制猎人必须移动才能获得正奖励

### 3. **包围奖励（三角形内）**
```python
if in_triangle:
    area_reward = max(0, 20 - area)  # 面积越小奖励越大
    
    sum_dist = sum(distances)
    if sum_dist < 10:
        team_reward += (10 - sum_dist) * 1.0  # 越接近奖励越大
```

**特点**：
- 形成包围 → 根据三角形面积给奖励
- 包围后继续接近 → 额外奖励
- **鼓励既包围又接近**的策略

### 4. **碰撞惩罚（降低）**
```python
if hunter_i_pos == hunter_j_pos:
    collision_penalty -= 10  # 原来-50，降低到-10
```

**改进**：
- 降低惩罚值，避免过度抑制移动
- -10的惩罚 < +2.0*多步接近的奖励

### 5. **成功捕获奖励**
```python
if captured:
    team_reward += 200
```

**特点**：
- 巨额奖励，是最终目标
- 成功条件：`all(distance <= 1) and in_triangle`

### 6. **基础时间惩罚**
```python
team_reward -= 0.5
```

**特点**：
- 小惩罚，避免无限拖延
- 不影响主要的接近奖励机制

## 🔄 核心改进

### 改进1：正奖励机制
- **旧**: 所有行为都是负奖励，只能"扣得少"
- **新**: 接近行为有正奖励，主动追求"赚得多"

### 改进2：动作激励
- **旧**: 移动风险大（碰撞-50），不如不动(-1)
- **新**: 不动惩罚-2.5，接近奖励+1.5，移动更划算

### 改进3：包围后的动力
- **旧**: 包围后面积奖励饱和，没有继续接近的动力
- **新**: 包围后有额外的距离奖励，鼓励继续缩小包围圈

### 改进4：降低碰撞恐惧
- **旧**: -50的碰撞惩罚让猎人畏手畏脚
- **新**: -10的惩罚可以被多步接近奖励弥补

## 🎮 预期行为改变

### 训练初期：
- 学习基本接近行为
- 避免严重碰撞
- 尝试包围猎物

### 训练中期：
- 形成有效包围
- 在包围状态下继续接近
- 协调避免碰撞

### 训练后期：
- 快速包围
- 动态调整位置
- 高效完成捕获

## 📊 监控指标

训练时关注：

1. **Average Reward**: 应该逐渐上升（从负数上升到正数）
2. **Success Rate**: 应该稳步增长
3. **Average Steps**: 成功时应该变短
4. **Static Actions**: 不动动作的比例应该降低

如果发现：
- 猎人仍然不动 → 增大静止惩罚到-3.0或-5.0
- 碰撞过多 → 增大碰撞惩罚到-15
- 不包围只追逐 → 增大包围奖励系数
- 包围但不接近 → 增大包围内的距离奖励系数
